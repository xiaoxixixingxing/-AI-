# 手机预览：从代码到扫码上手

> 本文为目标 A——「在自己手机上扫码看到真小程序」的逐步操作清单。
> 您的 AppID：`wx093891285de90e79`，已写入 `project.config.json`。

---

## 0. 前置说明

- 本期跑 **mock 模式**（无 Supabase 后端），扫码看到的雅集/琴馆/琴友都是 fixture 数据
- **请求白名单暂不需要配**，因为 mock 模式下小程序不会发起任何外部请求
- 真实登录、报名、视频房间需等 P3/P4 与 Supabase 接入

## 1. 在您的电脑上把代码拉下来

打开终端（Mac 的"终端"或 Windows 的"PowerShell"），任选一个文件夹（比如桌面）：

```bash
cd ~/Desktop
git clone https://github.com/xiaoxixixingxing/-AI-.git guqin-yaji
cd guqin-yaji
git checkout claude/analyze-xiaohongshu-requirements-yV2ES
```

如果还没装 git：Mac 自带；Windows 装 https://git-scm.com/

---

## 2. 安装 Node.js 与项目依赖

- 装 Node.js **22 LTS**：https://nodejs.org/
- 装完在终端验证：`node -v` 应输出 `v22.x.x`

然后在 `guqin-yaji/` 目录下：

```bash
npm install
```

约 1-2 分钟。装完会有个 `node_modules/` 文件夹（很大，正常）。

---

## 3. 编译小程序

```bash
npm run build:weapp
```

或者保持监听模式（改代码自动重编译）：

```bash
npm run dev:weapp
```

编译成功后会生成 `dist/` 目录，这就是要给微信开发者工具打开的产物。

---

## 4. 安装并配置微信开发者工具

1. 下载稳定版：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开后会要求**扫码登录**——用您**注册 AppID 时的微信号**扫
3. 点 **+ 新建项目** → **小程序**

填写：
- **项目名称**：古琴云雅集
- **目录**：选 `guqin-yaji/` 这个**根目录**（不是 dist/）
- **AppID**：会自动从 `project.config.json` 读取 `wx093891285de90e79`，不用手填
- **后端服务**：不使用云服务
- **模板**：不要选模板，用当前目录已有文件

点 **确定**，工具会自动加载并显示模拟器。

---

## 5. 在工具里预览效果（PC 端先试）

进入工具后您会看到三个区域：模拟器、编辑器、调试器。

- 左上角点 **编译** 按钮（或 Ctrl/Cmd + B），模拟器里就能看到首页
- 模拟器顶部可切机型，建议选 **iPhone 12** 或 **iPhone 13 Pro**
- 试着点首页的雅集卡 → 进入详情 → 点报名 → 应弹出"请先登录"

如果 PC 端正常，就可以推到手机了。

---

## 6. 推到您自己手机（体验版）

工具右上角 → 点 **预览** 按钮：

1. 工具会生成一个二维码
2. 用**手机微信**扫这个码
3. 微信里会自动打开您的小程序——这就是真机体验

> 第一次扫如果提示"未将自己加为体验者"，到 https://mp.weixin.qq.com → **管理 → 成员管理 → 体验成员** 添加您自己的微信号，再扫一次。

如果想让别人也能扫：
- 工具右上角点 **上传** → 填版本号（如 `0.1.0`）+ 描述 → 上传到微信后台
- 然后 https://mp.weixin.qq.com → **版本管理 → 体验版** → 提交为体验版
- 该页面会给一个二维码，加入"体验成员"的人扫码即可

## 7. 常见报错排查

| 现象 | 原因 / 解决 |
|---|---|
| 工具提示 AppID 无效 | 您注册的 AppID 不是您当前登录工具的微信号——必须是同一人 |
| 模拟器空白 / 转圈 | 检查左下角"详情 → 本地设置 → 不校验合法域名"是否勾上（开发期需要勾） |
| 报"请勾选不校验域名" | 同上，因为 mock 模式没真实请求所以勾不勾都行，但保险起见勾上 |
| 真机扫码进不去 | 工具上点的是 **预览** 还是 **上传**？预览只对自己可见，且二维码 30 分钟过期 |
| 编译出 `node_modules` 报错 | `rm -rf node_modules && npm install` 重装 |
